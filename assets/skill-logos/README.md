# Skill logos

The SVG files are source copies. The portfolio embeds them inline in `index.html`, with unique IDs for gradients/clipping and a 32px display size. The admin can edit those inline icons.

- React, Django REST Framework, Kotlin, Jetpack Compose, PostgreSQL, scikit-learn, Vite, SQLite, Java, Android, Firebase and Arduino: [Devicon](https://github.com/devicons/devicon), downloaded from its `master` branch. See `DEVICON-LICENSE.txt`.
- Espressif (representing ESP32): [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/espressif.svg), distributed under [CC0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md). Displayed in Espressif red.

Swing uses its parent Java brand. Room and CameraX use their parent Android brand. Firebase Auth and Firestore use their parent Firebase brand. These are ecosystem logos, not separate product-specific logos.

AI ChatBot, GPS, IoT Sensors, Real-Time Web, and Data Visualization & Reporting are general capabilities rather than specific brands; their descriptive SVG symbols are retained.

Brand marks belong to their respective owners and identify the technologies used, without implying endorsement.
