# TrustMart — Verified Second-Hand Marketplace

## Short portfolio description
TrustMart is a second-hand marketplace that connects buyers, sellers and moderators through a React website and two native Android apps. A shared Django REST API supports listing verification, personalized recommendations, messaging, order management and dispute resolution.

## Project-card description
A verified second-hand marketplace with a React website, two Kotlin Android apps, personalized recommendations and moderator-led listing reviews and disputes.

## Full project post / caption
Introducing TrustMart — a second-hand marketplace built around a more transparent buying and selling experience.

Developed as an HND Software Engineering final project, TrustMart brings together three interfaces: a website for buyers, sellers, moderators and administrators; a native Android app for buyers and sellers; and a dedicated native Android app for moderators. All three connect to the same Django REST API and shared data model.

Buyers can discover products, filter listings, save favourites, receive personalized recommendations and contact sellers. Sellers can upload product photos and verification evidence, manage listings and monitor orders. Moderators review submissions and handle disputes, while administrators oversee users, listings, transactions, promotions and reports.

The project also demonstrates an escrow-style order lifecycle, including simulated checkout, delivery confirmation and dispute outcomes. Card and PayHere checkout are demonstrations; no real payments are processed.

Built with React, Vite, Tailwind CSS, Python, Django REST Framework, Kotlin and Jetpack Compose, with PostgreSQL support and a scikit-learn recommendation engine using TF-IDF and cosine similarity.

This project brings together full-stack development, native Android interfaces, role-based access, API integration and marketplace workflows in one connected system.

## Key features
- Buyer, seller, moderator and administrator roles.
- Product search, categories, condition, price and location filters.
- Personalized recommendations using search and listing-view history.
- Product photo galleries, seller details, wishlists and buyer reviews.
- Seller listing creation, editing and verification-evidence uploads.
- Moderator approval/rejection workflows with review feedback.
- Buyer/seller messaging and in-app notifications.
- Simulated Card and PayHere checkout with order tracking and delivery confirmation.
- Dispute reporting and moderator resolution.
- Admin tools for users, listings, categories, transactions, advertisements and reporting.
- Shared accounts and marketplace data across the website and Android clients.
